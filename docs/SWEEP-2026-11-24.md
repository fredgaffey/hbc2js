header), shared findings DB `tools/findings.mjs` (deb copy: `/tmp/hbc2js/findings.sqlite`,

## Method

One whole-bundle `decompile()` per app, then over **every** emitted function
(attributed by its `// fn#N` marker):

| check | what it flags | runtime meaning |
|---|---|---|
| `PARSE` | @babel/parser recoverable errors (undefined labels, unsyntactic break) | module does not load |
| `FREE` | identifier read or assigned with no binding and not a host global (host list = the original bundles' own free names, `--host-from`) | ReferenceError / implicit global |
| `TDZ` | `let`/`const` read textually before its declaration in the same function body | ReferenceError, always |
| `NEVER-WRITTEN` | `let x;` read, never assigned | `:deref` = TypeError if reached; `:copy` = moves `undefined` (mostly dead copies Hermes has too) |
| `READ-BEFORE-WRITE` | `let x;` read in straight-line code before every write (no loop, no closure) | same split |
| `STUB` | EM isolation stub (`ISOLATED FAILURE`), with its error code and reason | function throws when called |
| `WARN` | `decompile()` diagnostics; histogram only (not in the DB) | refusals |

Differential half (`tools/sweep/factory-diff.mjs`): load the original Metro bundle text
and the decompiled text, each in its own Node `vm` context behind a prelude that pins
`__d`/`__r` to capturing stubs; run **every module factory in isolation** against a
deterministic stub host (memoised callable "anything" Proxy for every `require`), then call
every exported function once with no arguments. Compare per module id: throw class,
`module.exports` type / keys / per-key types, call outcome class. HBC-only apps (Ignite,
q7 (bench input-q7)) run the decompiled side alone and report ReferenceErrors the stub host cannot
explain. The function-restricted oracle in `src/harness/hbc-equiv.ts` (spec 28 §9.4) needs a
caller-supplied driver per function, so per-function differential execution was not built;
repros are checked with `tools/sweep/repro.sh` (every fetched hermesc, `equiv --hbc`,
`REPRO_FLAGS="--no-pass X"` to bisect the pass).

Expensify (99k functions) does not fit a whole-bundle decompile next to the other jobs on deb
(31 GB shared); it was swept with `static.ts --dir` over the perf lane's complete export tree
`~/perf/out/ex-k` (exported 2026-11-24 18:31, perf-export code before the main merge — so its
`PARSE` row is the for-of label bug already fixed on main in `54cd6b5`). No factory diff for it.

## Triaged as benign / not decompiler bugs

- `NEVER-WRITTEN:<name>@AssignmentExpression.right:in-paramless-catch:copy` (#3 by count,
  every app, every version): a catch whose binding was elided keeps `rN = __exc;` reading a
  never-assigned `let __exc`. The value is dead; emit-shape noise worth cleaning, no behaviour.
- `READ-BEFORE-WRITE` / `NEVER-WRITTEN` `:copy` on registers (#1, #2): dead moves of a
  register Hermes itself never initialised (`r9 = r4` before `r4` is set, value unused);
  sampled 6 across 3 apps, all dead.
- `NEVER-WRITTEN:_eN_N@*`: an environment slot the bytecode never stores (checked fn#11336
  Ignite: slot 1 has no `StoreToEnvironment` in the bytecode either) — faithful.
- `NEVER-WRITTEN:rN@__hbc_iterClose(arg0)`: an early `return` inside a printed `for...of`
  calls `__hbc_iterClose(undefined)` (no-op); the native `for...of` closes the iterator itself.
- `FREE:<name>` host names (`Node`, `EventSource`, `cancelIdleCallback`, `NativeModules`
  on Expensify without its own host list): globals the original code reads.
